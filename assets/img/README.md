# Logo da RBCIP

Coloque aqui o arquivo da logo com o nome exato:

    logo.png

- Use a **versão branca** (a logo aparece sobre o cabeçalho azul-marinho).
- PNG com fundo **transparente** (ou SVG salvo como `logo.png`).
- O cabeçalho exibe a logo com **46px de altura** (a largura ajusta sozinha).

Enquanto o arquivo não existir, o cabeçalho mostra apenas o título (sem erro).
